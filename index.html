eBay Tracker v3.0 Privacy Notice

Updated: 11 October 2026

Purpose and operator

This is a private seller-tracking application operated by its account owner, Viet. It is being developed to record inventory, sales and fees for the owner's resale workflow. It is not a public sign-up service.

Information and use

With seller authorisation, the planned integration will read order and financial transaction information to match sales with tracker Item IDs and calculate amounts and fees. eBay responses can include buyer or account details; only information needed for the approved workflow should be retained. Seller-data imports and scheduled automation are not yet enabled.

Current development stage

The notification receiver stores incoming marketplace account-deletion notices, their signature headers and receipt times in a restricted Cloudflare inbox. These records are marked unverified until authenticity checks are implemented.

Receiving a notice does not establish that deletion has been completed. Verification and deletion processing must be completed before the integration is treated as operational.

Storage and access

Cloudflare hosts the receiver and notification storage. Google Sheets and Apps Script support the private tracker and planned imports. These providers may process data outside the user's country.

Access is controlled through the owner's accounts and the tracker's authorised collaborators; not every stored record is shared with every collaborator. The public privacy page does not display tracker records or credentials.

This public privacy notice is also hosted on GitHub Pages.

Credentials

The application does not request or store the seller's eBay login password. Seller sign-in takes place through eBay. Production API credentials and seller tokens are to be stored in the draft Apps Script project's Script Properties, not in spreadsheet cells, chat or vault notes.

Retention and requests

Unverified notification records currently await processing. Retention and verified deletion handling for imported data will be finalised before automated imports begin.

Privacy enquiries, access or correction requests can be directed to the tracker owner through existing contact arrangements. Seller authorisation can be revoked through eBay's account controls.

Future changes

Additional features may require additional eBay permissions and fresh seller consent. This notice will be reviewed when data use, storage or access changes.
